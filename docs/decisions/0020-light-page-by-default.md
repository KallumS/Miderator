# 0020 - A light page by default; dark on request

- **Date:** 2026-10-07
- **Status:** Accepted - replaces the default chosen in 0015

## Context

0015 followed Starting Blocks Notation and set the page dark by default. The
user, testing it, asked for black on white as the default, with dark mode as
the choice.

## Decision

The page is black ink on white paper unless **Dark page** (toolbar, View menu)
is turned on. The choice is remembered between launches. Everything else in
0015 stands: the window's chrome stays the house's dark scheme, and the accent
is shaded down on white.

## Consequences

- New users see what every other notation program shows them.
