Installing Noterator on a Mac
=============================

1. Drag Noterator into the Applications folder (the shortcut beside it).

2. The first time only: in Applications, RIGHT-click (or Control-click)
   Noterator and choose Open, then Open again in the box that appears.

   macOS asks because Noterator is not yet signed with an Apple Developer
   certificate. After this first time it opens normally with a double-click.

   If macOS says the app "is damaged and can't be opened", open Terminal
   (Applications > Utilities > Terminal), paste this line and press Return:

       xattr -cr /Applications/Noterator.app

   then open it again. That removes the "downloaded from the internet" mark,
   which is all the warning is about.

3. Sound plays through the General MIDI instruments built into macOS, so
   nothing else needs installing. Plug in a MIDI keyboard at any time - it
   is picked up by itself.

Press H in the app for the keyboard shortcuts.
