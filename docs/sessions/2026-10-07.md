# 2026-10-07 - From an empty repository to a working Mac app

## Asked

A Mac desktop notation app in the spirit of Dorico, MuseScore, Sibelius and
Notion, whose music mostly comes from the family's generators:

- a grid of staves, measures, clefs and time signatures that lines notes up
  vertically (harmony) and horizontally (time);
- input by mouse, computer keyboard and MIDI keyboard, with most of the music
  coming from generators and edited afterwards;
- automatic engraving: stems, beams, spacing, accidentals;
- playback through virtual instruments;
- chords and scales detected on the timeline, click a note or chord to hear
  it, MIDI and audio export of bars or the whole score, automatic CCs, and
  instrument awareness (a violin line is not a viola line);
- later: automation, articulation management, VST3 and CLAP.

Sources offered: ScaleView-for-Reaper, Midi-Suggester, Midi-Variator,
Starting-Blocks-Notation, Good-Idea, Orchestration-Helper, Midi-Catalogue,
AutoCC, and a zip of music theory and orchestration texts. Partway through:
**no Intel build**. At the end the user tested it on their Mac: "It works."

## Built

The whole first version - see the README and `docs/ARCHITECTURE.md`. In
numbers: about 11,000 lines of C++ and adapter Lua, 49 core tests and 4 app
tests, sixteen decision records, CI on Linux and macOS that hands the user a
`.dmg`. Five commits after the initial one, each pushed to
`claude/epic-hypatia-z0ya3r`.

## The route

- **Reading first.** The eight repos and ScaleView (a JUCE plugin) were cloned
  and their CLAUDE.md files read before anything was written. ScaleView being
  JUCE 8.0.15 decided the toolkit (0001). The family's house style - decision
  records, session logs, the colour scheme, "no `reaper.` in the engine" -
  was adopted wholesale.
- **The engines turned out to be pure.** Every `*_theory`, `*_idea`,
  `*_catalogue`, `*_vary` file has no `reaper.` in it - the house rule paid
  off. That decided 0003: run them, do not port them. All five adapters worked
  through a plain `lua5.4` harness before any C++ touched them
  (`tools/try_generators.lua`), which is still the place to test an adapter.
- **The first render was nearly right**, which is what porting Starting Blocks
  Notation's rules buys. The renders then showed: a final drum hit written as a
  sixteenth and a sixteenth rest (now a beat, up to the bar line); and two
  heads on one line (C and C#) drawn on top of each other - the crossed-head
  rule only looked for seconds, not unisons.
- **Three failing tests were the tests' fault.** C3 is the bass clef's second
  space, not line; C and C# is a unison, not a second; and the ledger line under
  the treble staff in D major is C#, not C. Each was checked against the music
  before the expectation changed.
- **The engraver was quadratic** in three places (rests, spacing, auto-voices
  each walked every element for every measure). Bucketing by measure took 200
  bars of eight busy parts to a quarter of a second in a debug build (0.02 s on
  the Mac runner); a test holds it there.
- **Inserting a multi-part result was a crash waiting to happen**: it kept a
  pointer to the target part while pushing new parts onto the same vector.
  Caught on reading it back, before it ran.
- **JUCE 8 removed the blocking `runThread`** on progress windows; audio export
  owns its window and reports in `threadComplete`.
- **First run under Xvfb**: the selected tab's label was invisible (dark ink on
  a dark tab). Tabs are now drawn as buttons, the chosen one in the accent.
- **The chord lane named a tune** - "C D", "A B" for a melody's eighth notes.
  A segment is now named only where notes overlap, or where three or more
  pitch classes all belong to the chord found (0014).
- **Four notes of C major read as A minor** in the Scale lane. Suggester's key
  finder cannot tell relatives apart on so little. The written signature now
  settles a near tie (+0.12); a clearly minor progression still reads minor
  under a C major signature, and a test says so.
- **Typed notes started in the wrong register** - a viola's first C was a
  violin's. An empty part now starts in the middle of the instrument's sweet
  register (0016).
- **Cmd+Z did nothing** on Linux: with a modifier held the key code arrives
  lower-case. Letters are compared upper-cased.
- **The worker restarted mid-session.** Nothing was lost, but nothing had been
  pushed either. The first commit went up straight after.
- **The Mac build compiled first time; one test failed only there.** It read a
  key's label through a reference into a temporary vector - undefined, and
  happened to work with GCC.
- **Suggester's chords overwrote the tune they were made for**, because every
  result went into the caret's part. Now they go beside it and Variator's go
  after it (0011); the test reproduces the string quartet case.
- **Proving the Mac's sound without a Mac**: `NoteratorAppTests` renders a bar
  through each synth and checks it is not silent. On the macOS runner it
  prints "rendering through Apple General MIDI (built into macOS)", RMS 0.023.
- **Universal to arm64** on the user's word; deployment target 11.0 (0012).
- Last: every compiler warning under JUCE's strict flags fixed (the options
  form of the WAV writer, a case for every clef, an unsigned seed).

## Not done yet

- Page view (systems on pages, title, margins). The galley is the only view.
- Dynamics, articulations, slurs, text; articulation switching for libraries.
- CC lanes to draw on; AutoCC's mode, depth and time-scale controls.
- VST3 and CLAP instruments per part; SoundFonts through the DLS synth.
- MusicXML export and import.
- Real-time MIDI recording (step input only).
- Two voices per staff at most; a third overlapping line is cut short in the
  notation (it still plays). Chords with notes of different lengths are drawn
  at the longest.
- Typing an accidental with a letter (it takes the key's; arrows adjust).
- The chord lane counts held melody notes as extensions (C6 for a tune's A over
  C). An accompaniment-only reading may be wanted.
- Developer ID signing and notarisation (needs the user's Apple account).
- Windows.
